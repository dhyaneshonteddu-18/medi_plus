# Medicine Images

This folder contains medicine product images for the MediCare Plus application.

## Image Guidelines
- Format: PNG or JPG
- Recommended size: 400x300px (4:3 aspect ratio)
- Max file size: 200KB per image
- Background: White or transparent

## Image Naming Convention
Use lowercase with hyphens:
- paracetamol.png
- ibuprofen.png
- amoxicillin.png
- etc.

## Adding New Images
1. Place image in this folder
2. Update the database seed.sql with the correct path: `/images/medicines/filename.png`
